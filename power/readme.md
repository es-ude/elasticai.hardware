# Elastic Power Modules
This folder includes three different version of power supply modules to build bipolar power supplies for custom boards. 
The corresponding KiCAD symbols and layouts are in our KiCAD-library ([Link](https://github.com/es-ude/kicad-library)).

## Version: External Power Supply
This board allows to connect an external power supply to this board using the Banana connectors.
A bill of materials (BOM) can be open here ([Link](2_ext_supply/bom/ibom.html)). Please open it via: Open in new tab.

## Version: DC/DC Power Supply (up to +/- 6V)
This board allows to generate a bipolar power supply on the board using small DC/DC converters.
A BOM can be open here ([Link](1_dcdc_mini/bom/ibom.html)). Please open it via: Open in new tab.

## Version: DC/DC Power Supply (up to +/- 20V)
This board allows to generate a bipolar power supply on the board using large DC/DC converters.
A BOM can be open here ([Link](0_dcdc_max/bom/ibom.html)). Please open it via: Open in new tab.
